ニーズ分析

Diagnosis

今の課題は、集客不足よりも転換率と訴求の精度

本件の目的整理

幅広い一般語で総当たりするのではなく、高単価案件に近いテーマを優先し、 検索、マップ、LINE、AI回答まで含めて「高額酒・まとめ売り・持ち込み相談に強い」印象を作ることが重要です。

現状の最大課題

  • どの流入が正式な成果につながっているか、GA4上で十分に判定できない
  • 高級ワイン、ワインセラー、法人大量買取など高利益テーマの受け皿ページが少ない
  • GBP上で買取専門店としての理解が弱く、販売店寄り検索も混在している

現状

流入はあるが、成果の見え方が弱い

必要施策

計測、LP、GBP、LINEを連動させる

目指す状態

高単価案件が選ばれやすい集客構造

自社分析

次に、実データと現行導線から、自社の強みとボトルネックを整理します。 どこに改善余地があるかを、集客と転換の両面で見ます。

自社分析

Owned Media / GBP / Brand

自社分析: 今ある強みと、取りこぼしている価値

Fact: 現在の強み

  • Organic Searchが主力で、自然検索の土台が残っている
  • 査定ページ、LINE査定ページには既に需要がある
  • GBPではルート検索とサイトクリックが強く、来店意図が見えている
  • 「近い」「すぐ相談できる」「持ち込める」という強みを持ちやすい

Issue: 現在の弱み

  • 高単価案件向けのLPや実績訴求が不足している
  • 販売店寄りの想起が混ざり、買取専門性が伝わりにくい
  • FAQ、査定基準、価格透明性の見せ方が弱い
  • CV計測が未整備で、どの流入が成果につながるか判断しにくい

自社の問題は「集客がゼロ」ではなく、`強みが高利益案件向けに翻訳されていないこと` にあります。

自社分析

Owned Analysis

Googleアナリティクス分析: 流入はあるが、成果計測が弱い

対象期間 2026/1/1-7/14

GA4累計データを基に、流入構成と導線需要を確認。

Organic Search 8,136

総セッション 15,041 のうち約54%。自然検索が主力チャネル。

Direct 5,829

約39%を占める一方、ブランド流入と計測未整理流入が混在。

CV設定 要再設計

`form_submit 2,283件` に対しキーイベント総数は `9件` で乖離。

Fact

  • Organic Searchが最大流入で、SEO品質が成果に直結している
  • 上位閲覧ページに `LINE査定の流れ` と `買取査定` が入り、査定導線需要が明確
  • モバイル利用が最多のため、スマホ導線の改善余地が大きい
  • 高単価案件に近い `ワインセラー` `高級ワイン` `LINE査定` `持ち込み` を別管理すべき

Implication / Action

  • `form_submit` `LINEクリック` `電話クリック` を正式CVとして再設定
  • UTM運用とチャネル定義を整理し、Directの内訳を見える化
  • スマホFV、追従CTA、電話/LINE配置を改善して取りこぼしを減らす
  • 高単価ページ群の流入・CVを個別KPIとして追う

自社分析

Owned Analysis

Search Console分析: 指名は強いが、非指名の買取需要を取り切れていない

Fact

  • 提供データは `2026年1月1日-7月14日` のクエリ別累計CSV
  • ページ軸・日付軸がないため、URL別SEO評価や月別推移は未実施
  • 指名系クエリが強い一方、一般買取系クエリの母数はまだ小さい
  • `森伊蔵 飲み方` `ウイスキー 終売 一覧` など情報収集クエリの露出が大きい

Implication

  • ブランド認知は一定あるが、新規の非指名獲得余地が大きい
  • コラム流入はあるものの、買取意図への接続設計が弱い
  • 広い一般語の総力戦より、勝ちやすく収益性の高いテーマ集中が現実的

流入源

指名系 + 情報収集系が中心

狙うべき次段階

非指名の買取比較・査定意図へ広げる

優先テーマ

高級ワイン、ワインセラー、持ち込み、LINE査定、整理需要

SEOは `一般買取ワードの総当たり` ではなく、 `ワインセラー 買取` `高級ワイン銘柄` `大阪 持ち込み 酒買取` `LINE査定 酒買取` のような高単価・高確度テーマから積み上げる方針が適しています。

Owned Analysis

MEO分析: 来店意図は強いが、見られ方が酒屋寄り

対象期間 2026/2-7

GBPスクリーンショットと補足データを基に整理。

総インタラクション 1,380

検索・マップでの露出自体は一定確保できている。

ルート検索 812

Webクリック 491件、通話 77件よりも来店意図が強い。

検索語句傾向 酒屋寄り

`liquor store` `whisky shop` など販売店想起が上位。

Fact

  • 近隣ユーザーの来店ニーズはあり、MEOは案件化余地の高い接点
  • 一方で買取専門店としての理解が弱く、販売店・酒屋文脈が混在
  • 2025年3月に閲覧ユーザー数ピークがあり、波及余地は確認できる

Action

  • GBPカテゴリ、説明文、商品/サービス名を買取寄りに見直す
  • 持ち込みのしやすさ、査定スピード、アクセス情報を強化する
  • 口コミ返信や投稿でも `安心` `高額査定` `持ち込み` を言語化する

自社分析

Owned Analysis

内部施策分析: 勝ち筋はあるが、受け皿設計が足りない

Fact

  • `LINE査定` `買取査定` への関心が高く、相談導線自体の需要はある
  • 自然検索とGBPの両方から接点があり、既存の集客土台は残っている
  • ザオウリカー本体は `持ち込み` `LINE` `スピード` `安心感` を強みにしやすい

Gap

  • 高級ワイン・ワインセラー一括買取の専用LP
  • 大阪・店頭持ち込み買取の訴求ページ
  • 法人・飲食店・酒販店向け大量買取ページ
  • 情報記事から査定へつなぐCTAと比較・安心コンテンツ

Lオクと役割を混在させず、ザオウリカーは `近隣持ち込み` `すぐ査定` `LINEで気軽に相談` `ワインセラーやコレクションのまとめ売り` に寄せた受け皿を増やすのが有効です。

比較軸を `SEO / AIO(LLMO) / CV` に固定すると、両社の強みは明確に分かれます。

比較軸 Five Needs JOYLAB
検索で見つかる力 カテゴリ・銘柄別ページが多く、SEOで面を取りにいく設計 価格表・カテゴリ・FAQ・店舗導線が整理され、SEOとCVを両立
AIに理解される力 情報量は多いが、LPは売る力優先でやや訴求先行 価格、方法、FAQ、店舗、法人導線が明快で理解しやすい
AIに引用される力 銘柄別ページ、価格推移、実績が多く引用素材が豊富 更新日付き価格情報や人気銘柄一覧が引用されやすい

競合分析

Competitive Analysis

Five Needs分析: SEO横展開と価格訴求が強い

Strength

  • カテゴリ別、銘柄別、価格推移ページが多く、検索面を広く押さえている
  • `お酒買取日本一` の訴求でブランド想起を作っている
  • 価格推移、買取実績、人気銘柄一覧があり、AIが拾える具体情報が多い
  • 大量買取や高く売るコツなど、周辺テーマもSEOで取りにいく設計

Implication for ZAO

  • `最短5分` `即現金化` `キャンペーン` で今すぐ相談したくなる導線
  • 電話とLINEの導線が強く、スピード感のある査定訴求が中心
  • ターゲットは `高く売りたい層` `高額酒保有者` `大量在庫を持つ法人`
  • ザオウリカーは `高価買取の根拠` `価格透明性` `実績の見せ方` を学びたい

Five Needs は、`検索で面を取る力` と `価格で動かす力` が非常に強い競合です。

  • ザオウリカーは `負担ゼロ` `安心感` `相談しやすさ` の訴求を強化したい

福ちゃん分析: 整理・処分ニーズへの寄り添いが強い

サイトの目的・特徴

  • 遺品整理、生前整理、閉店整理などで困る層から出張買取依頼を獲得する
  • お酒の価値が分からない人にも伝わるストーリー型の見せ方
  • 実績やお客様の声を多く出し、不安払拭に注力
  • 出張買取を特に安心感のあるサービスとして見せている

サービス・ターゲット・示唆

  • Webフォーム・電話相談、出張・宅配・店頭買取
  • 買取実績金額を公開しつつ、処分の悩みに寄り添う
  • 価値が分からない大量のお酒に困る一般ユーザーが主対象
  • ザオウリカーは `遺品整理` `生前整理` `まとめ売り` 文脈のLPで差別化余地がある
